# 物理模拟实验台

一个打开浏览器就能玩的二维物理游乐场：刚体碰撞、布料软体、烟流涡街、热传导、波纹与图灵斑图，共 4 大类 13 个可交互实验。所有模拟都在你的机器上实时计算，右侧面板同步显示数值诊断。

## 快速开始

```powershell
npm run dev
```

然后打开终端里提示的地址（默认 <http://127.0.0.1:7100>）。无需安装任何依赖。

## 快速上手

1. **用顶部四个页签选家族**：刚体 / 软体 / 流体 / 场。
2. **用"代表性问题"下拉框选场景**，画布上方会提示当前场景怎么玩。
3. **直接在画布上按住拖动**——每个场景的拖动含义不同（抓物体、注染料、涂热源、放引导点……），可拖动的障碍物都带**虚线描边**。
4. 好奇数值细节就看右侧**实时诊断**：能量、残差、自由度等随场景切换含义。

### 控制按钮与快捷键

| 操作 | 按钮 | 快捷键 |
| --- | --- | --- |
| 暂停 / 继续 | 暂停 | `空格` |
| 单步推进（自动先暂停） | 单步 | `S` |
| 回到标准初始状态 | 重置 | `R` |
| 换一个随机初始布局（刚体／粒子水槽／反应扩散／Boids 场景提供；刚体还会微调斜坡位置与朝向） | 打乱 | — |
| 切换家族 | 页签 | `1`–`4` |

**时间倍率**放慢或加快物理时间；**重力**对所有场景生效；**求解质量**提升迭代次数和网格分辨率（流体与场类场景的高分辨率在这切换）；**自适应迭代预算**会在掉帧时自动降档保流畅。

## 场景导览

### 刚体
- **堆叠与摩擦接触**：方块与圆盘落堆。拖起一块砸向塔身，或拖动虚线斜坡换个角度；点"打乱"换个初始布局。
- **斜坡冲量碰撞**：旋转矩形高速撞击圆盘。拖动斜坡改变入射角，比较反弹与滚动的差异。

### 软体
- **悬挂布料与障碍**：XPBD 约束网格。扯住布角摇晃，或把虚线障碍球拖到布的必经之路上。
- **保面积软体水球**：全局面积约束让它像水球一样挤不扁。用障碍球从下方顶它试试。
- **共旋 FEM 悬臂梁**：有限元版本的软体，应变以颜色标出。和上两个 XPBD 场景对照着玩最有意思。

### 流体
- **不可压缩烟流**：拖动注入染料与动量，看涡卷如何被压力投影保持不可压。
- **绕流圆柱 · 卡门涡街**：招牌场景。红蓝涡量在圆柱后交替脱落成街；拖动圆柱改变绕流，在流场里按住滑动可以轻柔地搅动尾迹。
- **SPH 粒子水槽**：粒子法的水。搅动、掀起、看它回落成平面。
- **浅水波与扰动**：用手指在水面划出长波，观察波前的传播与反射。

### 场
- **含孔板热传导 FEM**：一块带圆孔的金属板，边缘恒温、孔壁绝热。拖动涂抹热源；按住圆孔内部可以把孔拖到别处，网格会即时重建。
- **薄膜波动方程**：点击是雨滴，拖动是抚过水面。右侧诊断栏的"约束"一项是 CFL 数。
- **Gray–Scott 反应扩散**：两个方程自发长出珊瑚状花纹。涂抹空白处播撒反应物，或点"打乱"重新播种。
- **Boids 群体运动**：每条"鱼"只遵守三条局部规则，群体却涌现出队形。按住画布放置引导点指挥它们。

## 常见问题

- **画面卡顿？** 把"求解质量"调低一档；勾选"自适应迭代预算"后系统会自动处理。
- **残差是什么意思？** 每个场景的数值健康指标（约束误差、散度范数、密度偏差等），越接近零越守恒。不同家族之间不可直接比较。
- **模拟是物理精确的吗？** 数值格式是认真的（XPBD、压力投影、LBM、FEM 组装……），但参数为实时交互做了取舍。它适合建立直觉，不适合替代工程验证软件。

## 深入阅读

想改代码或了解数值细节？源码在 `src/` 下，每个求解器是独立模块，接口约定见 `src/core/simulation.js`。`npm test` 运行无界面数值测试。参考起点：XPBD（Macklin et al. 2016）、SPH（Müller et al. 2003）、浅水（Kass & Miller 1990）、LBM 综述（Chen & Doolen 1998）、Gray–Scott（Pearson 1993）。
